# Paradise Nursery — e-plantShopping

A responsive houseplant shopping cart application built with React, Vite, Redux Toolkit, and React Redux.

## Features
- Landing page with a plant-themed background and Get Started button
- Navigation links for Home, Plants, and Cart
- Three categories of houseplants, with six plants in each category
- Product cards with images, names, descriptions, prices, and Add to Cart buttons
- Redux-powered cart state and dynamic navbar item count
- Cart item quantity controls, delete action, item subtotals, and grand total
- Continue Shopping and Checkout (Coming Soon) actions

## Run locally
1. Install Node.js (LTS).
2. Open a terminal in this folder.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the local URL printed in the terminal.

## Build for deployment
Run `npm run build`. Vite outputs the production site to `dist/`.
